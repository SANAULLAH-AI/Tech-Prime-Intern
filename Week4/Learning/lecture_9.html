Naïve Bayes: Step-by-Step Example

Solving spam detection like a math problem

Example: Spam Detection Training Data

Spam: "Win money now", "Free prize click"
Not Spam: "Meeting tomorrow", "Project update"
Classify: "Win free money"

📚 Step 1: Count Words in Each Class Spam messages: "Win money now", "Free prize click" Word counts in Spam: win: 1, money: 1, now: 1, free: 1, prize: 1, click: 1 Total words in Spam = 6 Not Spam messages: "Meeting tomorrow", "Project update" Word counts in Not Spam: meeting: 1, tomorrow: 1, project: 1, update: 1 Total words in Not Spam = 4 Total messages: 2 Spam + 2 Not Spam = 4 Prior probabilities: P(Spam) = 2/4 = 0.5 P(Not Spam) = 2/4 = 0.5
📚 Step 2: Calculate Word Probabilities (with Add-1 Smoothing) For Spam class: Vocabulary size V = 10 (win, money, now, free, prize, click, meeting, tomorrow, project, update) P("win" | Spam) = (count("win" in Spam) + 1) / (total words in Spam + V) = (1 + 1) / (6 + 10) = 2/16 = 0.125 P("free" | Spam) = (count("free" in Spam) + 1) / (6 + 10) = (1 + 1) / 16 = 2/16 = 0.125 P("money" | Spam) = (count("money" in Spam) + 1) / (6 + 10) = (1 + 1) / 16 = 2/16 = 0.125 For Not Spam class: P("win" | Not Spam) = (count("win" in Not Spam) + 1) / (total words in Not Spam + V) = (0 + 1) / (4 + 10) = 1/14 = 0.071 P("free" | Not Spam) = (0 + 1) / (4 + 10) = 1/14 = 0.071 P("money" | Not Spam) = (0 + 1) / (4 + 10) = 1/14 = 0.071
📚 Step 3: Calculate P(Spam | "win free money") Using Bayes' theorem with Naïve assumption: P(Spam | "win free money") = P("win"|Spam) × P("free"|Spam) × P("money"|Spam) × P(Spam) Substitute values: P(Spam | "win free money") = 0.125 × 0.125 × 0.125 × 0.5 = 0.0009765625 Explanation: Multiply all word probabilities and prior probability
📚 Step 4: Calculate P(Not Spam | "win free money") Using Bayes' theorem with Naïve assumption: P(Not Spam | "win free money") = P("win"|Not Spam) × P("free"|Not Spam) × P("money"|Not Spam) × P(Not Spam) Substitute values: P(Not Spam | "win free money") = 0.071 × 0.071 × 0.071 × 0.5 = 0.00017850625 Explanation: Multiply all word probabilities and prior probability
📚 Step 5: Compare and Classify P(Spam | "win free money") = 0.0009765625 P(Not Spam | "win free money") = 0.00017850625 Since 0.0009765625 > 0.00017850625 → P(Spam) > P(Not Spam) ✅ RESULT: Classify as SPAM Why? The message "Win free money" has higher probability of being spam because words like "win", "free", and "money" appear more frequently in spam messages.

Key Takeaways:

  • Step 1: Count words in each class to build the model
  • Step 2: Calculate word probabilities using smoothing (handles unseen words)
  • Step 3-4: Multiply probabilities for each class (Naïve assumption: words are independent)
  • Step 5: Choose the class with the higher probability
  • Note: We can ignore P(words) in the denominator since it's the same for both classes

Support Vector Machines (SVM)

Finding the best boundary

SVM: Step-by-Step Example

Finding the best separating line

Example: Spam Detection

Spam: "Win money now", "Free prize click"
Not Spam: "Meeting tomorrow", "Project update"
Classify: "Win free money"

📚 Step 1: Convert Text to Numerical Vectors (TF-IDF) Vocabulary: [win, money, now, free, prize, click, meeting, tomorrow, project, update] Document 1 (Spam): "Win money now" Vector: [0.5, 0.5, 0.5, 0, 0, 0, 0, 0, 0, 0] Explanation: "win", "money", "now" appear → values 0.5 each Document 2 (Spam): "Free prize click" Vector: [0, 0, 0, 0.5, 0.5, 0.5, 0, 0, 0, 0] Explanation: "free", "prize", "click" appear → values 0.5 each Document 3 (Not Spam): "Meeting tomorrow" Vector: [0, 0, 0, 0, 0, 0, 0.5, 0.5, 0, 0] Explanation: "meeting", "tomorrow" appear → values 0.5 each Document 4 (Not Spam): "Project update" Vector: [0, 0, 0, 0, 0, 0, 0, 0, 0.5, 0.5] Explanation: "project", "update" appear → values 0.5 each
📚 Step 2: Understand the Goal - Find a Separating Line SVM Goal: Find a line (hyperplane) that: 1. Separates Spam from Not Spam 2. Has the LARGEST margin (distance to nearest points) 3. Uses only the closest points (support vectors) Simple 2D Example: Imagine plotting documents in 2D space: • Spam documents on one side • Not Spam documents on the other side • Draw a line between them with maximum distance from both sides Key Insight: The line is defined by: w·x + b = 0 where w = weight vector, x = document vector, b = bias
📚 Step 3: Identify Support Vectors Support Vectors = Documents closest to the boundary For our example: Support Vector 1 (Spam): "Win money now" → Closest spam document to the boundary Support Vector 2 (Not Spam): "Meeting tomorrow" → Closest not spam document to the boundary Why these matter: • Only these points define the boundary • All other points are further away • SVM only needs to remember these support vectors! Margin = Distance between support vectors and the line Larger margin = Better generalization = More confident predictions
📚 Step 4: Calculate the Decision Function After training, SVM learns: • Weight vector w = [w₁, w₂, ..., w₁₀] (one weight per word) • Bias term b = a constant number Decision Function: f(x) = w·x + b where x = document vector, w = learned weights, b = learned bias Example (simplified): Let's say after training: w = [0.3, 0.3, 0.1, 0.4, 0.2, 0.2, -0.3, -0.3, -0.2, -0.2] b = -0.1 Explanation: Positive weights for spam words (win, money, free, etc.) Negative weights for not spam words (meeting, tomorrow, etc.)
📚 Step 5: Classify New Document "Win free money" Step 5a: Convert to vector "Win free money" → [0.5, 0.5, 0, 0.5, 0, 0, 0, 0, 0, 0] (win=0.5, money=0.5, free=0.5, others=0) Step 5b: Calculate f(x) = w·x + b f(x) = (0.3×0.5) + (0.3×0.5) + (0.1×0) + (0.4×0.5) + ... + (-0.2×0) + (-0.1) = 0.15 + 0.15 + 0 + 0.2 + 0 + 0 + 0 + 0 + 0 + 0 - 0.1 = 0.5 - 0.1 = 0.4 Step 5c: Make Decision If f(x) > 0 → Classify as SPAM ✅ If f(x) < 0 → Classify as NOT SPAM Since 0.4 > 0 → RESULT: SPAM Explanation: The positive value means the document is on the "spam side" of the boundary line.
📚 Summary: How SVM Works 1. Training Phase: • Convert all documents to vectors • Find the line that maximizes margin • Identify support vectors • Learn weights (w) and bias (b) 2. Classification Phase: • Convert new document to vector • Calculate f(x) = w·x + b • If f(x) > 0 → Class 1 (Spam) • If f(x) < 0 → Class 2 (Not Spam) Key Advantage: Only support vectors matter! SVM doesn't need to store all training data, just the support vectors. This makes it memory efficient for large datasets.

Key Takeaways:

  • Step 1: Convert text to numerical vectors (TF-IDF or BoW)
  • Step 2: SVM finds the best separating line with maximum margin
  • Step 3: Support vectors are the closest points that define the boundary
  • Step 4: SVM learns weights (w) and bias (b) during training
  • Step 5: Classify by calculating f(x) = w·x + b and checking the sign
  • Why it works: Large margin = better generalization to new data

Decision Trees

Rule-based classification

Decision Trees

Making decisions through a tree of questions

How It Works:

Decision Tree = A tree of yes/no questions that lead to a classification
Each node asks a question about a feature
Follow the path based on answers → reach a classification

Tree Structure

Root: First question
Branches: Answers (yes/no)
Leaves: Final classification
Path: Series of questions → answer

Interpretability

✅ Easy to understand
✅ Shows decision rules
✅ Can visualize the tree
✅ Human-readable

📚 Example: Spam Detection Tree Decision Tree: 
                    Contains "free"?
                    ╱              ╲
                   │                │
                 YES              NO
                  │                │
        Contains "money"?    Contains "meeting"?
            ╱        ╲          ╱        ╲
           │          │         │          │
         YES         NO        YES        NO
          │          │          │          │
        SPAM      NOT SPAM   NOT SPAM   SPAM
Classify: "Win free money now" → Contains "free"? YES → Contains "money"? YES → Result: SPAM ✅

Advantages & Disadvantages:

✅ Advantages:
  • Easy to interpret
  • No feature scaling needed
  • Handles non-linear relationships
  • Can visualize decisions
❌ Disadvantages:
  • Can overfit easily
  • Unstable (small data changes → big tree changes)
  • May create complex trees
  • Not always best accuracy

Comparing the Algorithms

Understanding strengths and weaknesses

Naïve Bayes

✅ Pros:
• Fast training
• Simple
• Good baseline
• Works with small data

❌ Cons:
• Naïve assumption
• May not be most accurate

SVM

✅ Pros:
• High accuracy
• Good with many features
• Memory efficient
• Generalizes well

❌ Cons:
• Slower training
• Less interpretable

Decision Trees

✅ Pros:
• Very interpretable
• No scaling needed
• Handles non-linear
• Easy to visualize

❌ Cons:
• Can overfit
• Unstable

📚 When to Use Each: Use Naïve Bayes when: • You need a quick baseline • Training data is small • Speed is important • Simple implementation needed Use SVM when: • You want high accuracy • You have many features • You have enough training data • Memory efficiency matters Use Decision Trees when: • Interpretability is important • You want to understand decisions • Non-linear relationships exist • You need human-readable rules

General Recommendation:

Start with Naïve Bayes as a baseline, then try SVM for better accuracy. Use Decision Trees when you need to explain why a classification was made.

Evaluation Metrics

Measuring model performance

How Good is Your Model?

Metrics for classification tasks

Basic Metrics

📊 Accuracy:

(Correct predictions) / (Total predictions)
Example: 90% accuracy = 90 out of 100 correct

📊 Precision:

(True Positives) / (True Positives + False Positives)
How many predicted positives are actually positive?

More Metrics

📊 Recall:

(True Positives) / (True Positives + False Negatives)
How many actual positives did we find?

📊 F1-Score:

2 × (Precision × Recall) / (Precision + Recall)
Balance between precision and recall

📚 Confusion Matrix Example Spam Detection Results: Predicted Spam Not Spam Actual Spam 80 20 Not Spam 10 90 Calculations: Accuracy = (80 + 90) / 200 = 85% Precision = 80 / (80 + 10) = 88.9% Recall = 80 / (80 + 20) = 80% F1-Score = 2 × (0.889 × 0.8) / (0.889 + 0.8) = 84.2% Interpretation: • 85% of emails classified correctly • When we predict spam, 88.9% are actually spam • We catch 80% of all spam emails

Important Note:

Accuracy can be misleading! If 95% of emails are not spam, a model that always predicts "not spam" gets 95% accuracy but is useless. Always check precision and recall, especially for imbalanced datasets.

Practical Implementation

Using scikit-learn for ML

Implementing ML Models

Python libraries that make it easy

scikit-learn:

The most popular Python library for machine learning!
Provides implementations of Naïve Bayes, SVM, Decision Trees, and many more.

📚 Complete Example: Text Classification Step 1: Import Libraries from sklearn.feature_extraction.text import TfidfVectorizer from sklearn.naive_bayes import MultinomialNB from sklearn.svm import SVC from sklearn.tree import DecisionTreeClassifier from sklearn.model_selection import train_test_split from sklearn.metrics import accuracy_score, classification_report Step 2: Prepare Data documents = ["Win free money now", "Meeting tomorrow at 3pm", "Click here for prize", "Project update needed"] labels = ['spam', 'not_spam', 'spam', 'not_spam'] Step 3: Convert to Features vectorizer = TfidfVectorizer() X = vectorizer.fit_transform(documents) Step 4: Train Model # Naïve Bayes: model = MultinomialNB(); model.fit(X, labels) # Or SVM: model = SVC(); model.fit(X, labels) # Or Decision Tree: model = DecisionTreeClassifier(); model.fit(X, labels) Step 5: Predict new_text = ["Free money click now"] X_new = vectorizer.transform(new_text) prediction = model.predict(X_new) print(prediction) # ['spam']

Getting Started:

  • Install: pip install scikit-learn
  • Preprocess: Clean and tokenize your text first
  • Feature extraction: Use TfidfVectorizer or CountVectorizer
  • Train/test split: Always split your data (80/20 or 70/30)
  • Evaluate: Test on unseen data, not training data!

Text Classification is the process of automatically categorizing text documents into predefined classes or categories based on their content, using machine learning algorithms.

Text classification is everywhere! From spam detection to sentiment analysis, it helps us automatically organize and understand vast amounts of text data.

What is Sentiment Analysis?

What is Sentiment Analysis?

Sentiment analysis is the process of determining the emotional tone or opinion expressed in text, typically classifying it as positive, negative, or neutral.

# Example: Word embeddings in action king = [0.1, 0.3, -0.2, 0.8, ...] queen = [0.2, 0.4, -0.1, 0.7, ...] man = [0.0, 0.2, -0.3, 0.9, ...] woman = [0.1, 0.3, -0.2, 0.8, ...] # The famous analogy: king - man + woman ≈ queen

Advantages over BoW/TF-IDF

  • Much smaller dimensions
  • Captures semantic relationships
  • Enables vector arithmetic

The Semantic Relationship Discovery:

Traditional approach: "king" = [1, 0, 0, 0], "queen" = [0, 1, 0, 0] (no relationship)
Word embeddings: "king" = [0.1, 0.3, -0.2, 0.8], "queen" = [0.2, 0.4, -0.1, 0.7] (similar vectors!)
The magic: king - man + woman ≈ queen! 👑
Why it's amazing: The computer learned that kings and queens are both royalty, just like we did! 🤯

The Semantic GPS System:

Word embeddings are like a GPS for meaning - words with similar meanings end up close together in the vector space, just like similar places are close on a map! 🗺️

Sentiment Analysis Approaches

How to Analyze Sentiment

From simple rules to sophisticated machine learning

Sentiment Analysis Methods

There are several approaches to sentiment analysis, ranging from simple rule-based methods to advanced machine learning techniques.

Rule-Based Methods

  • Positive word lists: "good", "great", "amazing"
  • Negative word lists: "bad", "terrible", "awful"
  • Simple scoring: +1 for positive, -1 for negative
  • Handle negations: "not good" = negative

Machine Learning Methods

  • Bag of Words + Naive Bayes
  • TF-IDF + SVM/Logistic Regression
  • Word embeddings + Neural networks
  • Pre-trained models (BERT, RoBERTa)
# Example: Rule-based sentiment analysis positive_words = ["good", "great", "amazing", "excellent", "love"] negative_words = ["bad", "terrible", "awful", "hate", "disgusting"] def simple_sentiment(text): words = text.lower().split() pos_count = sum(1 for word in words if word in positive_words) neg_count = sum(1 for word in words if word in negative_words) if pos_count > neg_count: return "positive" elif neg_count > pos_count: return "negative" else: return "neutral"

The Rule-Based Confusion:

Text: "This movie is so bad it's good!"
Rule-based system: "I see 'bad' (-1) and 'good' (+1) = neutral (0)"
Human: "That's clearly positive - it's sarcastic praise!"
Result: Context and sarcasm are hard for simple rules! 😅

The Evolution of Sentiment Analysis:

Early days: "I love this!" → Count positive words
Modern approach: "I love this!" → Use context-aware embeddings → Predict sentiment with 95% accuracy
The difference: From word counting to understanding meaning! 🧠

Evaluation Metrics

How to measure the performance of text classification models

Measuring Model Performance

Understanding how well our classifiers work

Why Evaluation Matters

We need metrics to understand how well our text classification models are performing and to compare different approaches.

Basic Metrics

  • Accuracy: Correct predictions / Total predictions
  • Precision: True Positives / (True Positives + False Positives)
  • Recall: True Positives / (True Positives + False Negatives)
  • F1-Score: 2 × (Precision × Recall) / (Precision + Recall)

Advanced Metrics

  • Confusion Matrix: Detailed breakdown of predictions
  • ROC Curve: True Positive Rate vs False Positive Rate
  • AUC Score: Area under the ROC curve
  • Cross-validation: Robust performance estimation
# Example: Confusion Matrix for Sentiment Analysis from sklearn.metrics import confusion_matrix, classification_report # True labels vs Predicted labels y_true = ['positive', 'negative', 'positive', 'neutral', 'negative'] y_pred = ['positive', 'negative', 'neutral', 'neutral', 'negative'] print("Confusion Matrix:") print(confusion_matrix(y_true, y_pred, labels=['positive', 'negative', 'neutral'])) print("\nClassification Report:") print(classification_report(y_true, y_pred))

The Accuracy Trap:

Scenario: 90% of emails are spam
Naive approach: "I'll just predict 'spam' for everything!"
Result: 90% accuracy - looks great! 🎉
Reality: Model is useless - it never catches legitimate emails! 😱
Lesson: Accuracy alone can be misleading! Use precision and recall too! 📊

The Balanced Approach:

High Precision: "When I say it's spam, I'm usually right" (few false positives)
High Recall: "I catch most of the actual spam" (few false negatives)
F1-Score: Balances both precision and recall for a single metric! ⚖️

What is a Confusion Matrix?

A confusion matrix shows the detailed breakdown of correct and incorrect predictions for each class, helping us understand where our model struggles.

Binary Classification

Predicted Actual Spam Not Spam Spam 45 5 Not Spam 8 42

True Positives: 45 (correctly identified spam)
False Negatives: 5 (missed spam)
False Positives: 8 (false alarms)
True Negatives: 42 (correctly identified legitimate)

Multi-class Example

Sentiment Analysis: Actual vs Predicted Pos Neg Neu Pos 120 5 15 Neg 8 95 12 Neu 12 8 125

Diagonal: Correct predictions
Off-diagonal: Misclassifications
Pattern: Shows which classes are confused

Reading the Matrix

Perfect classifier: All numbers on diagonal, zeros elsewhere
Random classifier: Numbers spread evenly across all cells
Good classifier: Large numbers on diagonal, small numbers elsewhere

The Confusion Matrix Confusion:

Student: "Why is it called a 'confusion' matrix?" 🤔

The Diagnostic Power:

Confusion matrices are like X-rays for your model - they show exactly where the problems are! If you see many misclassifications between 'positive' and 'negative', your model might be struggling with sarcasm or context! 🔍

# Complete Text Classification Pipeline from sklearn.feature_extraction.text import TfidfVectorizer from sklearn.model_selection import train_test_split from sklearn.naive_bayes import MultinomialNB from sklearn.metrics import classification_report # 1. When to Use Each Method

PCA: When you want to reduce dimensions without considering class labels
LDA: When you have labeled data and want to maximize class separation

Key Differences Between PCA and LDA:

PCA (Unsupervised):
  • Goal: Maximize variance in the data
  • Input: Only features (X), no labels needed
  • Output: Components that capture most data spread
  • Use case: Data visualization, noise reduction, general dimensionality reduction
  • Components: Can have as many as original features
LDA (Supervised):
  • Goal: Maximize class separation
  • Input: Features (X) AND class labels (y)
  • Output: Components that best separate classes
  • Use case: Classification tasks, finding discriminative features
  • Components: Maximum = number of classes - 1

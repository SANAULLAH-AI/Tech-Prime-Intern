Think about these words: "king", "queen", "man", "woman". How are they related? Can you see patterns? Word embeddings help computers understand these relationships mathematically!

What is Semantic Analysis?

Semantic Analysis is the process of understanding the meaning of words, phrases, and sentences in context. It goes beyond syntax to capture what words actually mean and how they relate to each other.
Word Embeddings are numerical representations of words that capture semantic meaning. Words with similar meanings have similar vectors!
Applications: Machine translation, sentiment analysis, information retrieval, chatbots, recommendation systems

Key Challenge:

• Words can have multiple meanings (polysemy): "bank" = financial institution or river edge
• Context matters: "I saw a bat" - is it an animal or sports equipment?
• Relationships are complex: synonyms, antonyms, hyponyms, hypernyms
• Different languages express meaning differently

Semantic Analysis

What is Semantic Analysis?

Going beyond syntax to understand meaning

Simple Explanation:

Semantic Analysis = Understanding what words actually mean, not just how they're structured
Syntax tells us "The cat sat on the mat" is grammatically correct.
Semantics tells us a cat (animal) sat (action) on a mat (object) - we understand the meaning!

Word Relationships

📝 Types:
• Synonyms: happy = joyful
• Antonyms: hot ≠ cold
• Hyponyms: dog is a type of animal
• Hypernyms: animal includes dog
💡 Example:
"car" and "vehicle" are related
"car" is a hyponym of "vehicle"
"vehicle" is a hypernym of "car"

Semantic Roles

📝 Roles:
• Agent: Who does the action?
• Patient: What receives the action?
• Theme: What is moved?
• Location: Where does it happen?
💡 Example:
"The ninja stole my sandwich"
Agent: ninja
Patient: sandwich
Theme: sandwich (moved)

Applications

🌐 Machine Translation
Understand meaning across languages
🔍 Information Retrieval
Find documents by meaning, not just keywords
❓ Question Answering
Understand questions and find answers
💬 Chatbots
Understand user intent and respond appropriately

Why Semantic Analysis Matters:

  • Understand Context: "I saw a bat" - context tells us if it's an animal or sports equipment
  • Find Similarity: Know that "happy" and "joyful" mean similar things
  • Resolve Ambiguity: "The bank is closed" - financial institution, not river edge
  • Better Search: Search for "automobile" finds documents with "car" too

Word Embeddings Introduction

Representing words as vectors

What are Word Embeddings?

Turning words into numbers that capture meaning

Simple Explanation:

Word Embeddings = Numbers (vectors) that represent words
Words with similar meanings have similar numbers!
Instead of "king" = word, we have "king" = [0.2, -0.1, 0.5, ..., 0.3] (a list of numbers)

Key Concepts

📝 Distributed Representation:

Meaning is distributed across many numbers (dimensions), not just one

📝 Dense Vectors:

Usually 50-300 numbers per word (not sparse like one-hot encoding)

📝 Semantic Similarity:

Similar words have vectors that are close together in space

Properties

✨ Similarity
"king" and "queen" are close in vector space
✨ Relationships
king - man + woman ≈ queen
✨ Context
Words appearing in similar contexts have similar vectors
✨ Dimensionality
Typically 50-300 dimensions
📚 Example: Word Embeddings One-Hot Encoding (Old Way): "king" = [1, 0, 0, 0, 0, 0, ...] (sparse, huge vector) "queen" = [0, 1, 0, 0, 0, 0, ...] (no relationship shown) Word Embeddings (New Way): "king" = [0.2, -0.1, 0.5, 0.3, ..., 0.1] (dense, 100-300 numbers) "queen" = [0.19, -0.09, 0.48, 0.29, ..., 0.12] (similar numbers!) Key Insight: • Similar words have similar vectors • We can calculate similarity using cosine similarity or Euclidean distance • Relationships can be captured: king - man + woman ≈ queen

Why Word Embeddings?

  • Capture Meaning: Similar words have similar vectors
  • Dense Representation: Much smaller than one-hot encoding
  • Learn Relationships: Can find synonyms, antonyms, analogies
  • Works with ML: Neural networks can use these vectors

Word2Vec: Skip-gram

Predicting context words from a target word

Word2Vec Skip-gram Model

Learning embeddings by predicting context

How Skip-gram Works:

Skip-gram = Given a word, predict the words around it (context)
Example: "The cat sat on the mat"
If target word is "sat", predict: "The", "cat", "on", "the", "mat"

The Process

📝 Steps:
1. Pick a target word (e.g., "cat")
2. Look at words around it (context window)
3. Try to predict those context words
4. Learn embeddings that help with prediction
💡 Example:
Sentence: "The cat sat on the mat"
Target: "sat"
Context: "The", "cat", "on", "the", "mat"
Window size: 2 (2 words before, 2 after)

Key Features

✅ Good for:
Rare words, large datasets
✅ Context Window:
Usually 2-10 words around target
✅ Training:
Neural network learns to predict
✅ Result:
Word embeddings that capture context
📚 Skip-gram Example Sentence: "The cat sat on the mat" Window size: 2 Training Examples: Target: "The" → Predict: ["cat", "sat"] Target: "cat" → Predict: ["The", "sat", "on"] Target: "sat" → Predict: ["The", "cat", "on", "the"] Target: "on" → Predict: ["cat", "sat", "the", "mat"] Target: "the" → Predict: ["sat", "on", "mat"] Target: "mat" → Predict: ["on", "the"] Key Idea: Words that appear in similar contexts will get similar embeddings! "cat" and "dog" might both appear near "sat", "ran", "played" → They get similar vectors!

Why Skip-gram Works:

  • Context is Key: Words appearing in similar contexts have similar meanings
  • Distributional Hypothesis: "You shall know a word by the company it keeps"
  • Learns Relationships: Words with similar contexts get similar embeddings
  • Good for Rare Words: Works well even with words that don't appear often

Word2Vec: CBOW

Predicting target word from context

Word2Vec CBOW Model

Continuous Bag of Words - opposite of Skip-gram

How CBOW Works:

CBOW = Given context words, predict the target word
Example: "The cat sat on the mat"
If context is ["The", "cat", "on", "the"], predict: "sat"

The Process

📝 Steps:
1. Take context words around a position
2. Combine them (average or sum)
3. Predict the target word in the middle
4. Learn embeddings that help with prediction
💡 Example:
Sentence: "The cat sat on the mat"
Context: ["The", "cat", "on", "the"]
Target: "sat"
Predict "sat" from context!

Skip-gram vs CBOW

Skip-gram:
Word → Context (better for rare words)
CBOW:
Context → Word (faster training)
Speed:
CBOW is faster (fewer predictions)
Quality:
Skip-gram often better for rare words
📚 CBOW Example Sentence: "The cat sat on the mat" Window size: 2 Training Examples: Context: ["The", "cat", "on", "the"] → Predict: "sat" Context: ["cat", "sat", "the", "mat"] → Predict: "on" Context: ["sat", "on", "mat"] → Predict: "the" Key Idea: • CBOW averages context words to predict target • Faster than Skip-gram (one prediction vs many) • Good for frequent words • Less effective for rare words

When to Use Each:

  • Use Skip-gram: When you have rare words, large datasets, want better quality
  • Use CBOW: When you want faster training, have frequent words, smaller datasets
  • Both work well: For most applications, either is fine!
  • Default choice: Many people use Skip-gram for better quality

GloVe: Global Vectors

Combining global and local information

GloVe (Global Vectors for Word Representation)

A hybrid approach combining matrix factorization and local context

What is GloVe?

GloVe = Global Vectors - combines the best of both worlds!
• Uses global word co-occurrence statistics (like matrix factorization)
• Also uses local context windows (like Word2Vec)
• Result: Better embeddings that capture both local and global patterns

How It Works

📝 Steps:
1. Count how often words appear together
2. Build a co-occurrence matrix
3. Learn embeddings that predict these counts
4. Optimize to minimize prediction error
💡 Key Insight:
If "ice" and "water" appear together often,
their embeddings should be similar!

GloVe vs Word2Vec

Word2Vec:
Uses local context windows only
GloVe:
Uses global statistics + local context
Advantage:
GloVe often captures relationships better
Use Case:
Both work well, GloVe sometimes better
📚 GloVe Co-occurrence Matrix Example Text: "ice water ice steam water steam" Co-occurrence Matrix (window=1): ice water steam ice 0 2 1 water 2 0 2 steam 1 2 0 Key Idea: • "ice" and "water" appear together 2 times • "water" and "steam" appear together 2 times • GloVe learns embeddings where: - Words with high co-occurrence have similar vectors - The dot product of embeddings predicts co-occurrence counts Formula (simplified): w_i · w_j ≈ log(co-occurrence(i,j))

Why GloVe Works Well:

  • Global Information: Uses statistics from entire corpus, not just local windows
  • Efficient: Faster training than Word2Vec on large datasets
  • Better Relationships: Often captures analogies better (king - man + woman = queen)
  • Pre-trained Models: Available for many languages and domains

Properties & Applications

What embeddings can do

Amazing Properties of Word Embeddings

What makes embeddings powerful

Key Properties:

Word embeddings have amazing properties that make them incredibly useful for NLP tasks!

Analogies

📝 Famous Example:
king - man + woman ≈ queen

This works! The vector math captures the relationship:
• king is to man as queen is to woman
• The difference between king and man
• Applied to woman gives queen!
💡 More Examples:
• Paris - France + Italy ≈ Rome
• big - bigger + smaller ≈ small
• walk - walked + ran ≈ run

Similarity

📝 Cosine Similarity:
Measure how similar two words are:
• Similar words: high similarity (close to 1)
• Different words: low similarity (close to 0)
• Example: "happy" and "joyful" ≈ 0.85
💡 Applications:
• Find synonyms
• Document similarity
• Recommendation systems
• Search engines
📚 Applications of Word Embeddings 1. Text Classification: Use word embeddings as features for sentiment analysis, spam detection, etc. 2. Machine Translation: Translate words by finding similar embeddings in target language 3. Information Retrieval: Find documents similar to a query using embedding similarity 4. Recommendation Systems: Recommend items based on similar user/item embeddings 5. Neural Networks: Use embeddings as input to RNNs, LSTMs, Transformers 6. Named Entity Recognition: Identify entities using context from embeddings

Real-World Examples:

  • Google Search: Uses embeddings to understand query meaning
  • Amazon Recommendations: "Customers who bought X also bought Y" uses similarity
  • Translation Apps: Google Translate uses embeddings for word meaning
  • Chatbots: Understand user intent using semantic similarity

Practical Implementation

Using gensim and other tools

Implementing Word Embeddings

Python libraries that make it easy

Popular Tools:

There are great Python libraries for working with word embeddings!
You can train your own or use pre-trained models.

Gensim

✅ Best For:

• Training Word2Vec models
• Loading pre-trained embeddings
• Easy to use API
• Fast and efficient

💡 Simple Example:
from gensim.models import Word2Vec
model = Word2Vec(sentences)
model.wv['king']

Pre-trained Models

✅ Available:

• Word2Vec (Google News)
• GloVe (Stanford)
• FastText (Facebook)
• Many languages supported

💡 Usage:
Download pre-trained models
Use them directly in your projects
No training needed!
📚 Complete Example: Training Word2Vec with Gensim Step 1: Install and Import pip install gensim from gensim.models import Word2Vec Step 2: Prepare Data sentences = [ ['the', 'cat', 'sat', 'on', 'the', 'mat'], ['the', 'dog', 'ran', 'in', 'the', 'park'], ['the', 'bird', 'flew', 'in', 'the', 'sky'] ] Step 3: Train Model model = Word2Vec( sentences, vector_size=100, # Embedding dimension window=5, # Context window min_count=1, # Minimum word frequency sg=1 # 1=Skip-gram, 0=CBOW ) Step 4: Use Embeddings # Get embedding for a word vector = model.wv['cat'] # Find similar words similar = model.wv.most_similar('cat', topn=5) # Output: [('dog', 0.89), ('bird', 0.76), ...] # Word analogy result = model.wv.most_similar( positive=['king', 'woman'], negative=['man'] ) # Should find 'queen'!

Getting Started:

  • Install: pip install gensim
  • Train your own: Use your text data to train embeddings
  • Use pre-trained: Download Word2Vec or GloVe models
  • Experiment: Try different parameters (vector_size, window, etc.)
  • Practice: Find similar words, test analogies, use in your projects!
